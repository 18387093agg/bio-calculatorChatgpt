# Golden vectors
- 2500 kcal thiamine model: 1.5–1.7 mg/day.
- Low gastric acid is disclosed as a qualitative concern for non-heme iron only; no unsupported numeric penalty is applied, and heme iron remains separately modeled.
- Low gastric acid is disclosed as a qualitative food-bound B12 release concern; no unsupported numeric penalty is applied, and crystalline B12 has no food-protein release concern.
- A 0.5 mg actual intake maps below a 1.2 mg RDA marker; UL remains a marker, never a target.
